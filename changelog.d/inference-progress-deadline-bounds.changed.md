- The direct Agent API (`runInference`, `runInferenceWithInjections`) now bounds each provider call it makes at 30 minutes without a parsed provider event (`DEFAULT_INFERENCE_PROGRESS_TIMEOUT_MS`) when the call passes no `progressTimeoutMs`. Before, such a call had no bound beyond the adapter's own. It returns an expiry as an aborted result with `abortReason: 'timeout'`. Pass `progressTimeoutMs: Infinity` for the old behaviour.
- Context-manager's compression calls, which reach membrane through the membrane agent-framework gives each context manager, now carry `FrameworkConfig.inferenceProgressTimeoutMs` (30 minutes by default) when the call sets no `progressTimeoutMs` of its own. Before, a compression call had no bound beyond the adapter's own, and one that hung held its resident's next turn with it. On most adapters a compression call streams no events, so the bound covers the whole call: one that runs past it on a slow model now fails into context-manager's failure handling where before it finished. Raise `inferenceProgressTimeoutMs` if your compressions run that long.
