- **agent-framework now depends on `@animalabs/context-manager` `^0.26.0`**, where it depended on `^0.25.0`. So a fresh install takes 0.26.0. It's the first release whose `compile` reads `requestLimitTokens` and `RequestOverhead.messages`. The framework passes them to keep a request within `physicalWindowTokens`. On 0.25.1 the framework runs, but the compile doesn't read the limit, and the framework doesn't detect that. 0.26.0 also changes three things where tool calls share an id. Where a later call reuses an earlier call's id, it changes which call a tool result is paired with, and how compile provenance credits a moved result. Where one message holds several calls with one id, it keeps only the last, so membrane, which refused such a request before, now sends it, with the further results as text. **Prompt cache:** a store where tool calls share an id can compile a different request from 0.25.1's. Where it does, the cache can't serve that request from the first message that differs. Every other store compiles what it compiled before.
