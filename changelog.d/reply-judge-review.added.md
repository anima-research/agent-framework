- **Hosts and judge authors:** for the reply judge's refusals and failed turns:
  - `EventGate.providerCallsReleased()`, which the framework calls where an operator releases a provider wait, where a surgery lets go of the store, where an acceleration hold on an agent's calls ends, and where an agent ends, since the judge may then read another agent, so the judge rules' batches held for a refusal go back to the judge without waiting for its stated end, and those held for one that stated no end, or no time left, go back to it then. A turn that changes what the judge reads, or the host's quiesce, still holds them until it ends, and a hold that still stands refuses the call again. A host that constructs its own `EventGate`, with a judge that a hold of the host's can refuse, has that judge reject a refused call with an error whose `providerAdmission` is `'deferred'`, and whose `retryAfterMs` is the hold's time left when it states one, as the framework's own judge does, and calls `providerCallsReleased()` when that hold lifts. The gate counts any other rejection as a failed call.
  - `ReplyJudgeDeps.refusal`, which says whether the framework would refuse the judge's call for an agent now. The judge asks it before reading the agent's context, and again before it rebuilds a request refused as too long, so a call it would refuse then builds no request. The framework supplies it, and the call's own admission still refuses one whose hold began since. A judge built with deps that leave it out reads the context, and the call alone refuses.
  - `ReplyJudgeDeps.failedLastTurn`, which gives the agent's last turn when it failed and no turn has started since, of the new type `FailedLastTurn` (`at`, when it failed). The framework supplies it. The judge then says that what woke that turn may be unanswered, and what runs it again, by the kinds of wake in the list it's given.
  - `UpcomingWake.when`, the time in words for a wake due at no time anyone can name, such as a batch the judge is deciding; shown in place of `at`.
