- Under `same_round_think_text_policy: private`, text an agent writes beside `think()` is now withheld on the fallback prose path too (XML tool mode, or a membrane without `roundContent`), as it already was in native rounds. That path routed the whole turn's prose at the end and never read the policy, so the reasoning the policy promises to keep private reached the channel. A round cut off at the output limit counts too, and so does one whose script hadn't returned when the turn ended, since it may have called `think`. The round is found by its place, as a refused `skip_reply`'s is, so a silencing send's hold on the turn's prose leaves it out: it isn't drafted. The delivery receipt counts it as the native path does: outside explicit routing, as kept private where a send or `skip_reply` has silenced the turn by the end of its round, and otherwise not at all; under `proseRouting: disabled`, as kept in the transcript; and under explicit routing there is no such receipt. The policy's texts, the `think` tool's description and `agent_settings`'s schema among them, no longer say "native", so an agent's tool definitions change and its prompt cache misses once after upgrading (#296).
- With a membrane that reports an all-refused XML attempt (`tool_attempt`, `tool_notice`), prose before the attempt is no longer taken for the next tool round's, so dropping a round's prose at the turn's end (a refused `skip_reply`'s, or a private `think`'s) leaves it to go out (#296).
