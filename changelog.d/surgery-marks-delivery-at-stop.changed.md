- Once `stop()` has begun, an awareness delivery pass that is already running claims no further mark: a request it has on the wire ends within that request's deadline, and the marks still due stay in the journal for the next start. In 0.22.2 a pass went on until it had attempted everything due, each request within its own deadline, so a `stop()` that waited for a `syncDiscordAwarenessMarkers()` waited for all of it.
