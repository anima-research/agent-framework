- `WakeProvenance.batchChannels`: the registered channels of a debounced batch in which no message addressed the agent, those the host resolved; before, nothing named them, and a batch whose events named no channel or author, only routes the host resolved, had no provenance at all, where it now has these and the `at` of its newest event that isn't a `chat:system` notice (a coalesced render's latest occurrence counts as a message), so its wake's `InferenceRequest.wakeAt` is set, where it was absent.
- `InferenceRequest.wakeChannels`: those channels on the gate wake for such a batch, those the framework names, set by the framework for hosts to read rather than set; a start merged from several requests carries every one's channels, and the framework's own wakes that continue a turn with no locus, unless its own wake named a channel that resolves to none, carry the channels the turn's starts gathered; before, no request carried them.
- `GateEventInfo.folds`: set by the framework on a coalesced render it admits, which folds its batch's every occurrence while its `tags` are the latest's; the gate then never takes it as a `chat:system` notice.
- `cameFrom` option on `ChannelRegistry`'s `deliverSpeech` and `routeSpeech`: the channels a turn with no locus came from, each with how the agent is shown it, which the failure's reason then names; the framework passes it for such a turn's plain speech and a sleep's announcement, and before, neither took it.
- `byDesign` on the failure passed to `ChannelRegistry`'s `onRouteFailure` option: set when a turn's plain speech, or a sleep's announcement, had no channel and its batch named the channels it came from, which the failure's reason names; before, no failure was marked so.
