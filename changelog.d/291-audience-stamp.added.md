- Every row the framework stores now says who it is for, in its metadata (#291). `metadata.audience` lists the agents the row is meant for, computed when it is written: the agent a write is delivered to; for an admitted inbound message, the recipients admission delivered it to; and nobody for one a tune-out holds. `metadata.ownRowOf` names the agent whose own row it is: its rounds and tool results, a puppeted call, and the rows the framework writes for that agent's own turn (clock rows, `[continue]` rows, batched-wake lines, notices about its own speech, routing or failures, a derived agent's inheritance and framing). "Own" goes by who stored the row, not by its participant, so mail a shared fork's parent sends it is the fork's to read, not the fork's own row. Mail and agent-lifecycle notices also name their recipient as `metadata.dendrite.to`. Both keys are the framework's: a write through it replaces any stamp its metadata carried. The stamp is metadata only, so compiles and requests are unchanged. Rows stored earlier carry none. Writes an earlier version left in the deferred-write queue are stamped when the queue is restored at boot, as this version stamps a write it queues: for the agent they are queued for, and for nobody when they carry a tune-out's hold (`metadata.tuneOut`). Any write the framework stores with that hold is for nobody, whichever agent's store it lands in. Exported for reading and writing it: `audienceOf`, `isOwnRowOf`, `withAudience`, `asOwnRow`, `storeOwnRow`, `AUDIENCE_KEY`, `OWN_ROW_KEY` and the `AudienceStamp` type. This is the stamp the presentation index (#291) reads, written ahead of it.
- The agent registry records where each agent's own rows are stored, apart from the slots it observes: `AgentRecord.ownSlot` (and `AgentSpec.ownSlot`, which the framework fills from how it opens the agent's context) is a `MessageSlotRef`, `{ namespace: null }` for the residents' shared slot, a namespace for an isolated slot, and a branch too for a shared fork. New queries: `ownSlotOf(name)`, `slotOwners(slot)`, `observersOf(slot, { held })` and `readersOf(slot)`, with `RESIDENTS_SLOT`, `sameSlot` and `observedSlot`. Residents own the shared slot; the subconscious owns `subconscious/<resident>` and reads the shared slot through the observe edge it always declared. `readsSharedSlot` (on specs and records, and the registry's `readsSharedSlot` and `sharedSlotReaders`) is deprecated: a record's flag is now derived from the split, and a spec or record without `ownSlot`, one restored from an earlier version included, is read as its flag meant, so nothing needs migrating. `ObserveEdge.fromMessageId` is added beside `fromSequence`, which is deprecated; nothing reads either yet.
