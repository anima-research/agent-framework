- **Consumers of the reply judge's verdicts:** `judgeState.last.verdict` in gate_status and the `gate:judge-verdict` trace's `verdict` can now be `'refused'`, beside `'reply'`, `'wait'` and `'error'`, for a call whose request the framework refused to send. Such a call has usually sent no request; one asked once more after the provider refused its first request as too long has sent that one. `judgeState.verdicts` has a matching `refused` count, which the type requires.
  - **Migration:** code that handles each value of that union exhaustively needs a `'refused'` case, and code that builds a `judgeState.verdicts` of its own, such as a typed fixture of `getStatus()`'s result, needs a `refused` count.
  - **Unchanged:** what `'reply'`, `'wait'` and `'error'` mean. This change requires no sibling version beyond those 0.33.0 requires, and raises no sibling package's version range.
