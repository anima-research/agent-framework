- **Edit/delete/reaction-remove markers no longer count as conversational input** (#157). `isConversationalInjection` exempted only `chat:reaction`, so the RFC-001 marker tags `chat:edited`, `chat:deleted` and `chat:reaction-remove` (now delivered as synthetic incoming messages by e.g. zulip_mcp) cleared explicit-send suppression — an edit notice arriving right after a `send_message` re-opened auto-routing for the same round's prose. The four tags live in a shared `NON_CONVERSATIONAL_TAGS` set (`src/mcpl/tags.ts`), and `ChannelRegistry` now also skips them when tracking the default publish locus, so a marker can no longer retarget outbound speech or become the reply anchor.
