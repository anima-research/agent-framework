- `AgentConfig.thinkingBinding`'s identity also covers whether the request leaves out effort rows the framework wrote for the agent (`FrameworkConfig.effort`). A context manager compares that identity to decide whether a stored reply keeps its signed thinking. When it changes, the next compile leaves the agent's stored replies' thinking out, as a change of model does, rather than sending thinking whose binding no longer matches the request. It changes when a function's answer moves between a level and `undefined`, when membrane refuses the agent's rows, and when a restart unsets the setting or sets it again. Where no such row is stored, the identity is as before.
