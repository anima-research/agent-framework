- MCPL RFC-014 tool presence (`toolHints: true`):
  - A move between static and dynamic takes effect when the server's `tools/list` states it, not when a hint announces it, and the agent is told where the tool went once a rebuild of the model's tool list has published it. When the host's own re-read (after a reconnect or a lost `rev`) moves a tool, it rebuilds the tool list at once.
  - Each `ended` id is told once while the host runs: told ids are kept in memory, an id counts as told only once a notice or a result carrying it reached the agent, and it is forgotten once the server stops reporting it. Rare interleavings, such as a `toolsets--look` overlapping another read of the same server, can tell one twice.
  - `toolsets--look` naming a tool shows its signature, description and input schema, as before; the README no longer calls that its whole definition. What look's own re-read of the server changed is in its answer when it restates everything, and otherwise told as a notice.
