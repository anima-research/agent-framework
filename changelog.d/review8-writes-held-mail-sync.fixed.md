- Held mail whose copy the boot finds in its recipient's store is released only once the store has synced, as a delivery releases it. After an import of an earlier release's deferred writes whose sync failed, the copy could be in memory only, while the release was written to the registry's recovery file at once, so a crash could lose the copy with the mail already released. A sync that fails now leaves the mail held, and it isn't delivered a second time.
