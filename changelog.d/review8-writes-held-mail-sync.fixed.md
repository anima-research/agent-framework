- Held mail whose copy the boot finds in its recipient's store is released only once the store has synced, as a delivery releases it. After the boot stored an earlier release's deferred writes and the store's sync failed (this release's import, or 0.32.0's flush of its restored queue at a serving boot), the copy could be in memory only, while the release was written to the registry's recovery file at once, so a crash could lose the copy with the mail already released. A sync that fails now leaves the mail held, and it isn't delivered a second time.
