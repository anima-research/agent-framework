- `healthSnapshot()` reports each agent's `upcomingWakes`: what will wake it with no new event that the framework knows of, soonest first and at most eight, as `{ at?, kind, certain }`. `kind` is the new `UpcomingWakeKind` (`heartbeat`, `reminder`, `self-wake`, `sleep-end`, `debounce`, `judge-batch`, `queued`, `provider-hold`), also set on `UpcomingWake`. No wake's description is included, since it can quote a reminder or a queue reason. The field is left out when it can't say: when the read fails, and when the heartbeat is heartbeat-mcpl. A timer in any other MCPL server isn't listed.
- `EventGate.upcomingWakes` gives an agent the gate doesn't wake only its own self-wake and a sleep naming it, since a batch or an untargeted sleep doesn't reach it.
