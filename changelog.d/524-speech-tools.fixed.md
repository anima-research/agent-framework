- `history--search` finds what an agent said through a send tool: a call of `channel_publish`, `send_message`, `reply_message`, `send_dm`, `reply_to_message`, `send_file`, `send_scheduled_message`, `create_poll`, `edit_message`, `say` or `whisper`, by that name on any server, is found by the words it carries, which search used to leave out. The semantic index reads the same words, labelled with the tool's bare name as before, now also under telegram-mcpl's argument names (`send_message`'s and `send_scheduled_message`'s `message`, `reply_to_message`'s `text`, `send_file`'s `caption`, `create_poll`'s `question` and `edit_message`'s `new_text`) and for Eidoverse's `say` and `whisper` (`text`). An established semantic index walks on from where it stopped, less its overlap window, so a send it had already walked past before this release, outside that window and not edited since, stays out of it; plain search finds it (anima-research/connectome-host#524).
