- A closed channel's invitation offers the reply its agent's prose routing reads. In explicit mode it offers a `>>` prefix, as before; in hybrid mode, a `>>>` one. In locus mode, the default, it says that plain text goes to the channel the latest `[routing]` notice names, that a reply with no prefix reaches it when that notice names it, and that otherwise, or with no such notice, a send tool of the server's does; for a tuned-out channel, whose messages start no turn, it points only to the send tool. In disabled mode it points only to a send tool of the server's. Before, it offered a `>>` prefix in every mode, and locus and hybrid mode post such a line as text, prefix and all, to the turn's channel.
