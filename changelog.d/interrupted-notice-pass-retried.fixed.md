- At boot, an agent the restart interrupted no longer has its record settled with notices it owed the primary still untold. That happened when its context couldn't be read, or when a notice's write to the primary failed: the failure was logged, and no later boot looked again. Now its record stays interrupted and each later boot tries again, passing only the notices not yet passed, and a recipient already told of the interruption isn't told again. A notice declined for the primary, with no one to tell, still lets the record settle.
