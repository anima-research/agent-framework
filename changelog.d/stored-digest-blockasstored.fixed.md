- `sourceBodyDigest`, and the `storedBodyDigest` it stamps at ingestion on both MCPL lanes, now take each block's stored form from context-manager's own `blockAsStored` (context-manager 0.22.0) instead of a copy of its transform (#252). A body holding a `tool_use` whose input isn't an object now hashes as the store keeps it: the store hands it back with `input: {}` and the value kept in `unparseableInput`, and the copy left it as given, so its stored copy didn't match its `storedBodyDigest`. Such a body's digest changes. The other 28 bodies in the real-store test hash as before.
  - A block the store refuses on write is digested as given, since it has no stored form.
  - A digest is now a digest under the context-manager release that computed it: a release that changes what the store keeps, such as its set of image signatures, changes the digest of a body it touches.
