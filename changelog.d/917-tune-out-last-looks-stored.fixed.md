- **Hosts with a persistent subconscious:** its last look at each tuned-out channel is now stored, and a start keeps it, also for a channel its server registers only after the host has started. So after a restart, its next cadence look at a channel counts only the messages held there since its last one, as before the restart. Before, the store refused every write of the looks, whose keys held a NUL byte; the failure was only logged, and a restart forgot every look, so every held message counted as new (#917).
