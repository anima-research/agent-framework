- Rewind recovery (#737) removes whole, complete tool exchanges by matching
  unambiguous IDs in both directions, including split result and signed/sharded
  call bodies. Separate system notices remain on presented windows; legacy raw
  removal requires an exact contiguous interval or declines unchanged.
  Missing/mismatched IDs (even adjacent), incomplete or mixed call/result bodies,
  hidden/foreign content and barriers decline, never falling back to one endpoint.
  Descriptors count UTF-8 JSON bytes and top-level images of selected bodies only,
  not intervening notices. See `docs/recovery-b.md` for compatibility and repair.
