- Text a participant or a server supplied no longer reads as the framework's own in an agent's context. A value the framework names in its own text, such as a channel's label, an author's or guild's name, a send's failure reason, a server's error text, or a server's tool and toolset names, titles and descriptions, stays on its line: each run of line breaks in it, in any form, shows as a space. A value the agent is told to pass back to a tool, such as a channel or message id, is written so it can be passed back exactly: one that holds a line break, one of the framework's openings, a quote, a backslash or whitespace at its edges is written as JSON that stays on one line and parses back to it, and a toolsets tool, toolset or instance selector with whitespace at its edges reaches what has that name exactly before anything with the trimmed name. And a bracket opening the framework, context-manager or membrane writes into an agent's context, such as `[drafts]`, `[Channel invitation]`, `[Recall …]` or `[continuing]`, is marked with a backslash (`\[drafts]`) in a server's or a participant's text: in a channel message, a pushed event, a context injection, console and API input and a Discord message as they're stored, and in channel_open's backscroll. Other tools' results, such as fetch_history's, are left as their tools returned them. Messages stored before this change keep their text as stored, apart from a Discord message a history sync rebuilds, which is written as new ones are.
