- Resident inference has a stall bound on every provider (#268). Each agent turn's stream, the direct Agent API's calls and MCPL servers' inference requests now pass membrane's `progressTimeoutMs`, which ends a provider call that goes that long without a parsed provider event. Keepalives don't count, so a provider that holds a stream open with them while generating nothing no longer hangs a resident with no error, no retry and no trace. Before, the Anthropic adapter's idle watchdog was a resident's only bound, and once keepalive bytes renew that watchdog (antra-tess/membrane#94) nothing bounds such a stream; on other adapters a resident's stream had no bound at all.
  - The bound is `FrameworkConfig.inferenceProgressTimeoutMs`, 30 minutes by default (`DEFAULT_INFERENCE_PROGRESS_TIMEOUT_MS`). The direct API takes `progressTimeoutMs` per call in `InferenceOptions`; callers that pass none now get the 30-minute default too. A value membrane would read as no deadline (NaN, zero or negative) gets the default wherever it's given; `Infinity` turns the bound off.
  - A stretch with no parsed event counts as no progress whatever the model is doing, such as thinking a provider doesn't stream, so keep the bound above the longest such stretch you expect. A call that streams no events is bounded as a whole: an MCPL server's non-streaming request, and any call through an adapter that doesn't stream, such as membrane's Images adapter.
  - An agent turn's expiry fails the request as a retryable `timeout`, "No stream progress within <n>ms (inferenceProgressTimeoutMs)": the error policy retries it, each attempt with a fresh deadline, and a stall that persists exhausts the turn with that reason and its classification. With the default policy that is four attempts, about two hours at the default bound. Before, a stream that ended on a deadline settled the turn as exhausted ("Stream aborted: timeout") with no retry. The direct API doesn't retry: it returns an expiry as an aborted result with `abortReason: 'timeout'`.
  - A resident whose turn exhausts on a timeout gets its `[inference-failed]` marker without the advice to change approach, which is about what a request carries and doesn't fit a stall.
