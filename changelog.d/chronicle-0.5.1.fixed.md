- **agent-framework now asks for `@animalabs/chronicle` `^0.5.1`**, where it asked for `^0.5.0`. chronicle 0.5.1 stores JSON objects with their keys in the order they were written (in a JavaScript object, its own property order) and hands them back that way, where 0.5.0 sorted them. Where agent-framework opens a store itself, from `storePath` or in offline recovery, it does so with its own copy of chronicle, so asking for `^0.5.1` makes every install of agent-framework take that fix for those stores, whatever range the host or another package asks for. A store the host opens and passes in as `store` follows the host's copy of chronicle, which this range doesn't reach. Nothing is migrated: as chronicle 0.5.1's changelog says, objects written before through its JSON-writing methods keep their sorted keys, and objects stored before as raw bytes now come back in the order of their bytes (in a JavaScript object, its own property order), so a request built from them can change once after the upgrade.
