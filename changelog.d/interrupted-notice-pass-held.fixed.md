- At boot, a notice an interrupted agent owes the primary that is kept in memory rather than stored (a surgery's hold, or the receiving agent's manager refusing its work) doesn't let the agent's record settle as though the primary had been told, since a stop or a crash before the hold's release would lose the notice: the record stays interrupted, and the next boot passes the notice unless the hold's release stored it first. No hold can be in force while the boot passes notices today, so nothing changes yet, and the settle stays true if one ever is.
