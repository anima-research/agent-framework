- At boot, a notice an interrupted agent owed the primary that was kept in memory rather than stored (a surgery's hold, or the receiving agent's manager refusing its work) no longer lets the agent's record settle as though the primary had been told. A stop or a crash before the hold's release would lose the notice, and no later boot would look again. The record now stays interrupted, and the next boot passes the notice unless the hold's release stored it first. No hold can be in force while the boot passes notices today, so nothing changes yet, and the settle stays true if one ever is.
