- **Hosts that store their own `system_change` rows that change tools or system text:** such a row no longer goes out as stored, beside the agent's tools. The framework treats it as a declaration of the agent's tools and system text, as it treats the agent's own change rows.
  - **Who needs to act:** a host that changes an agent's tools or system text by storing such a row in the agent's context. On a model that takes a change in its context (`Membrane.takesToolOrSystemChanges`, from membrane 0.10.4), the agent's request folds the row into what it declares, the agent declares only what differs from its own tools and system text, and a move of the agent's head removes the row. On a model that takes none, and with an earlier membrane, the agent's next request removes the row and goes on the agent's own tools and system text. A request through the direct API (`Agent.runInference`, `runInferenceWithInjections`) leaves the row out, unless it goes on the agent's recorded head and the row is part of what that head's request declares. A row that the agent's context can't remove stays in the store, such as a row of the residents' slot for the subconscious. In the residents' slot, one resident's removal takes the row from every resident.
  - **Migration:** change the agent's tools or system text through the framework: its tools, its system prompt, or a system-position context injection. On a model that takes a change, the framework then declares the change.
  - **Unchanged:** a `system_change` row that carries only `effort` goes out as stored, and rows on other branches stay. No sibling package needs a new version beyond this release's own ranges (`@animalabs/membrane` `^0.8.0 || ^0.9.0 || ^0.10.0`, `@animalabs/context-manager` `^0.27.0`). The declarations themselves need membrane 0.10.4.
- **Hosts that read an agent's stored rows:** on a model that takes a change in its context, an agent's store now holds `system_change` rows that declare its tools and system text, and a move of its head removes them again.
  - **Who needs to act:** a host whose reader of stored rows takes conversation alone, such as a window of recent messages, a transcript, or a count of a row's tokens. Such a row has no text, and its participant is `system`.
  - **Migration:** tell such a row by `isSystemChangeMessage(message)`, now exported, and leave it out, as a stored injection is left out (`storedInjectionMarkOf`). The function reads the row's blocks, whatever metadata the row carries, since a copy of a context and a host's own row carry no mark. A display can draw the row as one line, with the tools it defines and removes, and a count can take its JSON's length, as for a tool call.
  - **Unchanged:** on a model that takes no change, and with an earlier membrane, the framework stores no such row. No sibling package needs a new version beyond this release's own ranges.
- **Hosts with a table or `switch` that must cover every `TraceEvent['type']`:** `TraceEvent` names 3 more types, `head:declared`, `head:moved` and `head:resend` (under Added).
  - **Who needs to act:** a host with a `Record<…>` keyed on `TraceEvent['type']`, or a `switch` checked exhaustively with `never`.
  - **Migration:** add an entry for each of the three.
  - **Unchanged:** every other trace type, and its fields. No sibling package needs a new version.
- **Hosts that handle every `presentation:retracted` reason:** `PresentationRetractReason` has a new member, `'head-moved'`.
  - **Who needs to act:** a host whose code covers each value of the trace's `reason`, such as an exhaustive `switch`. It meets `'head-moved'` when a move of an agent's head removes change rows that another agent's window held, such as an observer's. A `head:moved` trace follows it and says which move it was, except where no head was recorded and the new one couldn't be stored.
  - **Migration:** handle `'head-moved'`, or let a default branch take it. No sibling package needs a new version.
  - **Unchanged:** the other reasons, and the trace's fields.
