- **Hosts that store their own `system_change` rows:** an agent on its head (`toolDeclarations: 'head'`, the default) no longer sends them.
  - **Who needs to act:** a host whose change rows reached its model before. They now stay out of the requests and the compile of every agent on its head, whose context manager the framework opens with a view that leaves them out: a resident's, an ephemeral agent's, isolated or derived, a resumed agent's and a conversation fork's.
  - **Migration:** set `toolDeclarations: 'entries'` on the agents that should send them. Under `'entries'` a host's change rows go out as stored. It needs no sibling version beyond this release's own ranges (`@animalabs/membrane` `^0.8.0 || ^0.9.0 || ^0.10.0`, `@animalabs/context-manager` `^0.27.0`).
  - **Unchanged:** the rows stay stored, and an inspection (`inspectAgentContext`) still shows them. The subconscious's view is as it was, since it already left out every change row not its own.
- **Hosts that handle every `presentation:retracted` reason:** `PresentationRetractReason` has a new member, `'head-moved'`.
  - **Who needs to act:** a host whose code covers each value the trace's `reason` can take, such as an exhaustive `switch`. It meets `'head-moved'` when a move of an agent's recorded head takes that agent's own system changes out of the record, and they leave another agent's window that held them, such as one that observes the agent. The `head:moved` trace after it says which move it was.
  - **Migration:** handle `'head-moved'`, or let a default branch take it. It needs no sibling version beyond this release's own ranges.
  - **Unchanged:** the other reasons, and the trace's fields.
